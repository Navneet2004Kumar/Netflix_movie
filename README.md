

🎬 Netflix Clone (ReactJS)

A modern Netflix-inspired web application built using React.js, featuring dynamic rows, a responsive banner, and categorized movies — just like the real Netflix UI.

🚀 Features

✅ Dynamic Movie Rows – Movies are organized into categories (Trending, Action, Comedy, Romance, etc.)
✅ Beautiful Banner – High-quality hero banner that changes dynamically
✅ Responsive Design – Fully responsive for mobile, tablet, and desktop
✅ Custom Components – Modular structure using React components
✅ Smooth UI/UX – Styled with CSS transitions, gradients, and hover effects
✅ Carousel (Optional) – Can add top carousel for trending movies
✅ Local Assets – Uses locally stored images for fast loading

🛠️ Tech Stack

React.js – Frontend library

CSS3 / Flexbox / Grid – Styling and layout

JavaScript (ES6+) – Logic and interactivity

Vite / Create React App – Development setup

Local images – For banners and thumbnails
